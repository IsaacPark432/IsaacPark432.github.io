Privacy Policy

Last updated: September 2026
← Home

Scope

This privacy policy covers personal automation applications built and operated by Isaac Park ("I", "me") that request access to Google account data (e.g. Gmail, Google Calendar, Google Drive, Google Sheets, Google Docs) via OAuth. These applications are for my own personal, individual use and are not distributed to, or intended for, other end users.

Data Access & Use

Any Google account data accessed through these applications (email content, calendar events, spreadsheet or document contents, file metadata) is used solely to operate personal automation on my own behalf — for example, summarizing email, tracking a personal budget spreadsheet, or managing my own calendar. Data is processed locally on infrastructure I own and control and is not sold, shared with third parties, or used for advertising.

Data Storage

OAuth tokens and any derived data are stored locally on my own self-hosted server. No data is transmitted to or stored by any third-party service beyond what is strictly required to call the relevant Google API.

Data Retention & Deletion

I retain data only as long as needed for the personal automation to function. Access can be revoked at any time via Google Account → Security → Third-party access, which immediately invalidates any stored tokens.

Contact

Questions about this policy or these applications can be directed to me via GitHub.
